# 《百年孤独》阅读工程

译本：范晔译本  
阅读时间：2026年6月  
阅读方式：原文全本阅读  

## 项目说明

本文件夹用于整理《百年孤独》的阅读笔记与研究思考。

不同于普通读后感，本项目尝试从人物、家族谱系、时间结构、意象、主题和比较文学等角度，理解马尔克斯如何通过布恩迪亚家族书写历史、孤独、重复与文明。

## 目录

### 01 人物论

整理主要人物的性格、命运与象征意义。

### 02 家族谱系

整理布恩迪亚家族七代关系。

### 03 时间结构

分析小说中的非线性叙事、循环时间与羊皮卷结构。

### 04 意象研究

整理冰块、小金鱼、黄色蝴蝶、猪尾巴、雨、羊皮卷等意象。

### 05 主题研究

分析孤独、历史循环、记忆与遗忘、女性、文明等主题。

### 06 比较文学

将《百年孤独》与《等待戈多》《局外人》《老人与海》《红楼梦》等作品进行比较。

### 07 我的问题

记录阅读过程中产生的真实问题。

## 当前核心判断

《百年孤独》不只是关于孤独的小说，更是一部关于历史循环、家族记忆和文明兴衰的小说。

真正震撼人的，不只是魔幻事件，而是一个家族在一百年中不断重复自己的命运。
